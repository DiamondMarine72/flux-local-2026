# Быстрый старт — Flux Local 2026

1. **Двойной клик** по **`flux-local-2026.exe`** в корне репозитория  
   или запустите **`START.bat`**
2. Либо **[Releases](../../releases/latest)** → скачайте тот же **`flux-local-2026.exe`**
3. Windows может спросить SmartScreen — «Подробнее» → «Выполнить»

> Файл **`flux-local-2026.exe`** — установщик/лаунчер под это репозиторий (flux-local-2026).
